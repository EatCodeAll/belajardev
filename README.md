# BelajarDev - Interactive Learning Lab

BelajarDev adalah platform pembelajaran interaktif berbasis web yang dirancang untuk membantu pemula menguasai konsep dasar pengembangan web (HTML) dan sistem operasi (Linux) melalui tantangan langsung (hands-on) di browser.

## 🚀 Fitur Utama

- **Interaktif Lab:** Kerjakan tantangan coding dan lihat hasilnya secara real-time.
- **Simulasi Terminal:** Belajar perintah dasar Linux melalui simulator terminal Bash yang terintegrasi.
- **Sistem XP & Progres:** Kumpulkan XP setiap kali menyelesaikan misi. Progres disimpan secara otomatis di browser.
- **Mobile First Design:** Tampilan profesional yang bersih dan dioptimalkan untuk perangkat seluler.
- **Clean Architecture:** Kode yang modular dan mudah dikembangkan lebih lanjut.

## 🛠️ Teknologi yang Digunakan

- **Frontend:** React 19 (TypeScript)
- **Bundler:** Vite
- **Styling:** Tailwind CSS 4
- **Icons:** Lucide React
- **Animations:** Tailwind Animate & Canvas Confetti

## 📦 Cara Menjalankan Lokal

1. Clone repository:
   ```bash
   git clone https://github.com/username/belajardev.git
   ```
2. Masuk ke direktori project:
   ```bash
   cd belajar-interaktif
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Jalankan mode development:
   ```bash
   npm run dev
   ```
5. Buka `http://localhost:5173` di browser Anda.

## 🚀 Deployment

Project ini siap di-deploy ke platform seperti Vercel, Netlify, atau GitHub Pages.
Untuk membangun versi produksi:
```bash
npm run build
```
